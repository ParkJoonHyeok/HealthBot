# 이전 계약

`guide.json`은 기존 Node 프로토타입의 증상 안내 응답을 고정한 회귀 기준입니다. Node와 Spring이 같은 파일로 비교합니다. 증상 매칭, 여러 진료과, 미확인 증상, 응급 우선 안내를 포함합니다.

이 파일은 의학적 정답 데이터가 아닙니다. 특히 “가슴 통증은 없고 콧물만 나요”도 기존 키워드 방식에서는 응급 표현으로 감지됩니다. 그 제한을 숨기지 않고 이전 중 동작 변경 여부를 확인하기 위한 사례로 남겼습니다. 의료 정확성 개선은 전문가 검토와 별도 평가를 거쳐 계약 변경으로 기록해야 합니다.

자동으로 현재 구현에서 이 파일을 덮어쓰지 마세요. 변경은 기대 행동과 이유를 함께 검토해야 합니다. HTTP 형식/오류, 병원 API의 XML 및 네트워크 처리는 backend 테스트에서 별도로 검증합니다.
